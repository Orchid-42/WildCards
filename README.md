# WildCards

A single-player card game with real animals. Build a deck during a run, battle themed rivals across three habitats, and level up your cards.

## Play on iPhone

1. Open the game's GitHub Pages address in **Safari**.
2. Tap **Share**, then **Add to Home Screen**.
3. Open WildCards from the home screen. It runs full screen and works offline after the first visit.

Progress is saved on the device (in the browser's local storage). Deleting the home-screen app or clearing Safari website data erases it.

## Files

- `index.html` — the whole game
- `art/` — one picture per card (`NNN_id.webp`)
- `sw.js` — offline cache
- `manifest.webmanifest`, `icons/` — home-screen app setup
